# CodeCraft

## Projektin kuvaus
CodeCraft on reseptisovellus, jonka avulla käyttäjä voi hakea reseptejä ja tutustua niiden tietoihin.

## Tavoite
Tavoitteena on toteuttaa helppokäyttöinen reseptisovellus, joka hyödyntää TheMealDB-rajapintaa.

## Toiminnallisuudet
- Reseptien hakeminen.
- Hakutulosten näyttäminen.
- Reseptien kuvien ja nimien näyttäminen.
- Ainesosien ja valmistusohjeiden näyttäminen.
- Virheilmoitukset, jos reseptejä ei löydy.

## Tekniikat
- HTML
- CSS
- JavaScript
- TheMealDB API

## Projektin tekijä
Yksilöprojekti.

## Projektin tila
Suunnitteluvaihe.
