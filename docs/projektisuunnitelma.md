# CodeCraft – Projektisuunnitelma

## 1. Projektin kuvaus

CodeCraft on reseptisovellus, jonka avulla käyttäjä voi etsiä reseptejä ja tutustua niiden tietoihin. Sovellus hyödyntää TheMealDB-rajapintaa.

## 2. Projektin tavoite

Tavoitteena on toteuttaa helppokäyttöinen ja toimiva reseptisovellus, joka toimii selaimessa.

## 3. Käyttäjän tarpeet

Käyttäjä tarvitsee sovelluksen, jonka avulla hän voi löytää reseptejä ja saada tarvittavat tiedot ruoan valmistamiseen.

## 4. MVP – ensimmäinen toimiva versio

Ensimmäiseen versioon toteutetaan:
- Reseptien hakeminen.
- Hakutulosten näyttäminen.
- Reseptin nimen ja kuvan näyttäminen.
- Ainesosien näyttäminen.
- Valmistusohjeiden näyttäminen.
- Ilmoitus, jos reseptejä ei löydy.

## 5. Käyttäjätarinat

- Käyttäjänä haluan hakea reseptejä, jotta löydän sopivaa ruokaa.
- Käyttäjänä haluan nähdä hakutulokset, jotta voin valita reseptin.
- Käyttäjänä haluan nähdä reseptin ainekset, jotta tiedän mitä tarvitsen.
- Käyttäjänä haluan nähdä valmistusohjeet, jotta osaan valmistaa ruoan.
- Käyttäjänä haluan saada ilmoituksen tyhjistä hakutuloksista, jotta tiedän, ettei reseptejä löytynyt.

## 6. Käytettävät teknologiat

- HTML
- CSS
- JavaScript
- TheMealDB API
- GitHub versionhallintaan

## 7. Projektin toteutus

Projekti toteutetaan yksilötyönä. Työ jaetaan pienempiin tehtäviin, joita seurataan GitHub Issues- ja Projects-toiminnoilla.

Koodin muutokset tallennetaan GitHubiin committeina.

## 8. Testaus ja julkaisu

Sovelluksen toiminta testataan selaimessa. Valmis sovellus julkaistaan verkossa, ja julkaistu versio testataan.

## 9. Dokumentointi

Projektin eteneminen, tehdyt muutokset, ongelmat ja niiden ratkaisut dokumentoidaan GitHubissa.
## 10. Sprinttisuunnitelma

### Sprintti 1 – Suunnittelu ja käyttöliittymä
- Reseptien hakunäkymän toteutus (60 min).
- Reseptisovelluksen ulkoasun viimeistely (120 min).

### Sprintti 2 – Reseptien hakeminen
- Reseptien hakeminen TheMealDB-rajapinnasta (90 min).
- Hakutulosten näyttäminen (60 min).

### Sprintti 3 – Reseptien tiedot ja virhetilanteet
- Reseptin tietojen näyttäminen (90 min).
- Tyhjien hakutulosten ilmoittaminen (30 min).
- TheMealDB-rajapinnan virhetilanteiden käsittely (45 min).
